## Keeping a High Traffic Site Fast

The right plan is the start. These habits keep it fast.

- **Cache everything you can.** On WordPress, LiteSpeed with LSCache serves ready made pages without running PHP. With root access, add Redis for object caching.
- **Put a CDN in front of static files.** India VPS plans are CDN ready, so images, CSS and scripts can come from edge locations.
- **Watch your resources.** Check CPU, RAM and disk use through peak hours, not only on quiet days.
- **Test before a big day.** If you run a sale or a launch, test your checkout under load a few days before.
- **Back up before every change.** Peak season is the wrong time to find out a restore does not work.
- **Keep software updated.** Old PHP versions and plugins slow your site down and open security holes.
